# 💧 HIDROVIABLE

Aplicativo web desarrollado con Streamlit para realizar una evaluación preliminar hidráulica, energética y económica de pequeñas centrales hidroeléctricas.

## Ejecutar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Descripción

Permite estimar:

- Altura neta y potencia eléctrica.
- Energía diaria y anual.
- Ingreso anual y flujo de caja.
- VAN y TIR.
- Periodo simple de recuperación.
- Proyección gráfica y tabular del proyecto.

> Los resultados son estimaciones preliminares y no sustituyen estudios hidrológicos, ambientales, de ingeniería o financieros.
